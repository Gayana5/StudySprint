# StudySprint

StudySprint — трекер учебных сессий для студентов. Приложение помогает планировать занятия, запускать таймер (Pomodoro или кастомный), оценивать продуктивность и видеть аналитику по предметам.

## Возможности
- Создание учебных сессий (предмет + длительность)
- Таймер с режимом Pomodoro и кастомным временем
- Оценка продуктивности после сессии
- Статистика по предметам и streak‑серии
- Цели на день и напоминания
- Локальное хранение данных (Hive)

## Технологии
- Flutter / Dart
- State management: `flutter_bloc`
- Локальная БД: `hive`, `hive_flutter`
- Уведомления: `flutter_local_notifications`
- Графики: `fl_chart`
- DI: `get_it`

## Архитектура
Проект организован по принципам Clean Architecture:
- `lib/domain` — сущности, репозитории, usecases
- `lib/data` — модели, источники данных, реализации репозиториев
- `lib/presentation` — UI, cubit'ы, страницы
- `lib/core` — общие сервисы, тема, утилиты

## Запуск
1. Установите Flutter SDK (стабильный канал) и убедитесь, что среда готова:
   ```bash
   flutter doctor
   ```

2. Установите зависимости:
   ```bash
   flutter pub get
   ```

3. Запустите приложение:
   ```bash
   flutter run
   ```
